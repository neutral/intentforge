# IntentForge guides

Use IntentForge to develop in a persistent workspace while keeping software
definitions and project context close to the work. Start with a new IntentForge
environment and initialize Atlas in the project.

Start with [setup](setup.md), then [develop one change](first-task.md).

| Task | Guide |
| --- | --- |
| Install, choose a workspace, and open the applications | [Run IntentForge](setup.md) |
| Return to work or stop the environment | [Saved environments](setup.md#return-to-saved-environments) |
| Connect an agent to Intent and Atlas | [Agent configuration](setup.md#connect-an-agent-or-use-a-command) |
| Maintain working guidance or learn from selected experience | [Trellis skills](setup.md#use-trellis-skills) |
| Back up storage and change the selected image | [Preserve and replace](setup.md#preserve-and-replace-deliberately) |
| Read context, direct a Worker, and review a change | [Develop one change](first-task.md) |
| Understand product ownership and terminology | [Components](components.md) |
| Build an image from selected application packages | [Distribution](../distribution/README.md) |
| Check supported platforms, verified behavior, and limits | [Verification](verification.md) |

Advanced setup covers [Compose](setup.md#advanced-compose) and explicit
[native Worker policy](setup.md#select-native-policy-for-a-fresh-worker).
