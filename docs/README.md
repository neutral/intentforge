# IntentForge guides

| Guide | Use it to |
| --- | --- |
| [Setup](setup.md) | Install the npm command, obtain the image, select a workspace, and return to a saved environment. |
| [Develop one change](first-task.md) | Read and author context, give a Worker a Direction, steer it, and review the result. |
| [Components](components.md) | Find product responsibilities, terms, and owning integration contracts. |
| [Distribution](../distribution/README.md) | Understand npm and image delivery and build an image from pinned component payloads. |
| [Verification](verification.md) | Identify the reviewed image, observed behavior, and remaining limits. |

The npm package includes these guides and the Compose recipe. The
[public repository](https://github.com/neutral/intentforge) also supplies the image
builder and runtime sources. Development tests, npm packaging, and release
coordination remain in the Forge development repository.
